# Gamepad Skin Server

Веб-сервер для отображения игрового контроллера с поддержкой смены скинов в реальном времени.

## Возможности

- Отображение состояния геймпада в браузере
- Смена скинов геймпада с помощью кнопок
- WebSocket для передачи событий в реальном времени
- Автоматическое переподключение при разрыве соединения

## Управление скинами

1. Нажмите и удерживайте **Start + Select** одновременно
2. Держите 2 секунды - появится индикация "готовности"
3. Отпустите кнопки - режим смены скина активирован
4. Используйте **DPad Left/Right** для переключения скинов
5. Нажмите **Start** или **Select** для выхода из режима смены

## API Endpoints

| Endpoint      | Метод | Описание             |
| ------------- | ----- | -------------------- |
| `/`           | GET   | Главная страница     |
| `/skin`       | GET   | Текущий скин         |
| `/list_skins` | GET   | Список всех скинов   |
| `/ws`         | GET   | WebSocket соединение |

## WebSocket события

Сервер отправляет события в формате JSON:

```json
{"t": "p", "d": "A"}    // Кнопка нажата
{"t": "r", "d": "A"}    // Кнопка отпущена
{"t": "s", "d": {"lx": 0, "ly": 0, "rx": 0, "ry": 0}}  // Стики
{"t": "sc", "d": {"name": "Red", "path": "/skins/sapa_red/", "index": 0}}  // Скин изменен
{"t": "sch", "d": true} // Начало смены скина
{"t": "ssr"}            // Готовность к смене скина
```

## Структура скинов

Скины располагаются в `assets/skins/<skin_name>/`:

```
assets/skins/sapa_red/
├── skin.json        # Метаданные скина
├── backend.png      # Фон
├── a.png, b.png...  # Изображения кнопок
└── ...
```

### skin.json

```json
{
  "name": "Red Theme",
  "body": {
    "image": "backend.png",
    "top": 0,
    "left": 0
  },
  "indicator": {
    "image": "indicator.png",
    "top": 10,
    "left": 10
  },
  "buttons": [{ "name": "South", "image": "a.png", "top": 100, "left": 200 }]
}
```

## Запуск

```bash
cargo run
```

Сервер запустится на `http://localhost:3000`

## Технологии

- **Rust** + **Tokio** - асинхронный сервер
- **Axum** - веб-фреймворк
- **Gilrs** - библиотека для работы с геймпадами
- **WebSocket** - real-time коммуникация
