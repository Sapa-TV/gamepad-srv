# Gamepad Skin Server

Веб-сервер для отображения игрового контроллера с поддержкой смены скинов в реальном времени. Предназначен для использования с OBS (dual PC gameviewer).

## Возможности

- Отображение состояния геймпада в браузере
- Смена скинов геймпада с помощью кнопок на контроллере
- WebSocket для передачи событий в реальном времени
- Автоматическое переподключение при разрыве соединения
- Сохранение выбранного скина в config.toml

## Управление скинами

1. Нажмите и удерживайте **Start + Select** одновременно
2. Держите 2 секунды - появится индикация "готовности"
3. Отпустите кнопки - режим смены скина активирован
4. Используйте **DPad Left/Right** для переключения скинов
5. Нажмите **Start** или **Select** для выхода из режима смены

## API Endpoints

| Endpoint | Метод | Описание             |
| -------- | ----- | -------------------- |
| `/`      | GET   | Главная страница     |
| `/skin`  | GET   | Текущий скин (JSON)  |
| `/ws`    | GET   | WebSocket соединение |

## WebSocket события

Сервер отправляет события в формате JSON:

**Состояние геймпада:**

```json
{ "ls": { "x": 0, "y": 0 }, "rs": { "x": 0, "y": 0 }, "b": 15 }
```

- `ls` - левый стик (x, y от -127 до 127)
- `rs` - правый стик (x, y от -127 до 127)
- `b` - битовая маска нажатых кнопок

**Команды:**

```json
{"cmd": "e"}   // Начало режима смены скина
{"cmd": "l"}   // Выход из режима смены скина
{"cmd": "r"}   // Готовность к смене скина
```

**Смена скина:**

```json
{ "skin": { "name": "Sapa Green", "path": "/skins/1_sapa_green/" } }
```

## Структура скинов

Скины располагаются в `assets/skins/<skin_name>/`:

```
assets/skins/1_sapa_green/
├── skin.json        # Метаданные скина
├── body.png         # Фон (тело контроллера)
├── a.png, b.png...  # Изображения кнопок
└── ...
```

### skin.json

```json
{
  "name": "Sapa Green",
  "body": {
    "image": "body.png",
    "top": 0,
    "left": 0
  },
  "indicator": {
    "image": "menu.png",
    "top": 284,
    "left": 426
  },
  "buttons": [
    { "name": "South", "image": "a.png", "top": 253, "left": 662 },
    { "name": "DPadUp", "image": "dpad-up.png", "top": 322, "left": 269 }
  ]
}
```

> **Примечание:** `top` и `left` - координаты изображения относительно левого верхнего угла контейнера.

## Конфигурация

Настройки хранятся в `config.toml`:

```toml
port = 3000
skin_path = "skins/1_sapa_green"
```

## OBS

### Single PC

1. Добавьте источник **Браузер**
2. Укажите URL: `http://localhost:3000`
3. Рекомендуемые размеры источника: **1408×1768**

### Dual PC

Сервер и OBS запущены на разных компьютерах в локальной сети:

1. Убедитесь, что файрвол не блокирует соединения на порту 3000
2. Добавьте источник **Браузер**
3. Укажите URL: `http://<локальный_ip_сервера>:3000`
4. Рекомендуемые размеры источника: **1408×1768**

> При запуске сервер отображает свой локальный IP адрес (например `192.168.1.100`)
> Порт по умолчанию 3000, изменить можно в `config.toml`.

## Запуск

```bash
cargo run
```

При запуске сервер отображает локальный IP адрес для доступа.

Сервер запустится на `http://localhost:3000` И на локальном адресе

## Debug режим

Для отладки добавьте `?debug=true` к URL:

```
http://localhost:3000?debug=true
```

Включает логирование WebSocket событий в консоль браузера.
